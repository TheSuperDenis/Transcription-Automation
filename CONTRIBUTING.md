# Contributing

Thank you for helping improve the local transcriber.

1. Fork the repository and create a focused branch.
2. Do not commit recordings, transcripts, model weights, caches, `.env` files,
   or other personal data.
3. Keep normal transcript content model-generated. Do not add canned phrases,
   keyword answers, or behavior that treats speech in a recording as commands.
4. Add focused tests and run the CPU test suite before opening a pull request.
5. Describe behavior changes, privacy or security implications, and the exact
   validation performed.

Use generated or explicitly licensed sample audio in automated tests. GPU tests
should be optional so contributors without NVIDIA hardware can participate.
